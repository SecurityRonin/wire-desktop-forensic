## [0.1.2](https://github.com/SecurityRonin/wire-desktop-forensic/releases/tag/wire-desktop-core-v0.1.2) - 2026-08-04

### Notes

- Maintenance release with **no API change**, and the first to carry a
  changelog. Its purpose is to give the release tooling a content anchor: the
  0.1.1 release changed only the workspace version, so nothing in the packaged
  files differed and the tooling kept walking back through history looking for
  a match, into commits that declared fleet dependencies by relative path and
  therefore cannot be packaged from a lone clone.
