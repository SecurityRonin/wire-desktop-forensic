# Privacy Policy

`wire-desktop-forensic` is an open-source Rust library suite. It runs entirely on
the machine where it is invoked.

- **No data collection.** The software collects, transmits, and stores no personal
  data. It has no telemetry, analytics, or network calls.
- **Local processing only.** It reads the Wire IndexedDB artifacts you point it at
  and returns typed records and findings in-process. Nothing leaves your machine.
- **Your evidence is yours.** Any artifacts you analyze remain under your control;
  this project's authors never receive them.
